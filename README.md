One Wi-Fi network name, 30 characters, built for make.fun's "Tell a Whole Story in 32 Characters" bounty ($2).

The entry is:

```
Baby's First Word Was Password
```

A baby's first word is supposed to be "mama" or "dada" — here it is the Wi-Fi password. In one line you get the character (the baby), the situation (a household where the password is said so often the baby learned it first) and the event (the first word itself). It lands on the first read, uses no stock Wi-Fi joke and no ex/router material, and every word earns its place.

## Run it

```sh
python3 main.py
```

`main.py` (Python standard library only, no network, no input files, no secrets) writes exactly that name — no trailing newline — to `/output/entry.txt`, asserting first that it is 1–32 characters and then verifying the bytes it wrote.
